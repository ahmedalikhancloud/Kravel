# Karl debugger artwork

The project-bound sprite is `kravel/web/karl-debugger.png`. It was made with the built-in image-generation tool in edit mode, using the earlier Karl sprite as the edit target. Its transparent background is preserved. The resource models are native Three.js geometry (capsules, cubes, slabs, and rings), not generated bitmap mockups. Mouse cursors are local SVG assets. No new image assets were generated for the WebGL redesign.

Final artwork prompt:

> Edit Karl into a cute Kubernetes debugger mascot. Remove clocks, rewind symbols, and all time-travel motifs. Keep the compact, friendly pixel-robot identity. Give him a terminal visor with pixel eyes and a >_ symbol, a magnifying sensor and handheld magnifier, a navy container body, Kubernetes wheel ears, a generic Docker-style badge, and a welcoming wave. Use polished 32-bit pixel art in navy, cobalt, cyan, amber, and mint. Show the full body on a genuinely transparent background. No lettering, watermark, or time symbols.
